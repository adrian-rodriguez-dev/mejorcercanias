# Proposal
## Why
La aplicación necesita una URL pública para consultar trenes desde el móvil sin servidor local.
## What Changes
- Publicar el build estático en GitHub Pages tras validación de main.
- Documentar URL y proceso automático de publicación.
## Capabilities
### New Capabilities
- `static-publication`: acceso público HTTPS y publicación de versiones verificadas.
### Modified Capabilities
Ninguna.
## Impact
GitHub Actions, configuración Pages del repositorio y README. Sin cambios en datos ni pantallas.
