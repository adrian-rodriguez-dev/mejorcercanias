# Why
El teclado móvil puede ocultar el campo de búsqueda y las opciones de estaciones o núcleos.

# What Changes
- Situar el campo enfocado arriba del área visible en móvil.
- Ajustar el alto del desplegable al espacio restante cuando cambia el teclado.
- Mantener navegación por teclado y comportamiento de escritorio.

# Impact
EditableSelect, estilos móviles y pruebas de navegador.
